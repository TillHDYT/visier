# VISIER

Survivor-Spiel plus Burg-Aufbau. Kompletter Spielcode.

## Start

```bash
npm install
npm run dev
```

## Spielcode

- `src/game/engine.ts` — Survivor: Kampf, Wellen, Drache, Feueratem
- `src/game/castle.tsx` — Burg: isometrisches Bauen, Angriff nur per Button
- `src/game/meta.ts` — Gold und Speicher
- `src/game/audio.ts` — Musik und Sounds
- `src/game/content.ts` — Gegner, Kapitel, Waffen
- `src/game/skills.ts` — Fähigkeiten
- `src/components/visor-app.tsx` — Menüs
- `src/styles.css` — UI
- `public/` — Bilder (Lava, Drache, Mauern, Runen)
